# Автоисправление Markdown (markdownlint --fix)

## Контекст

В `dmt` есть встроенный линтер документации на базе `markdownlint`, но он
**только находит** нарушения — автоисправления (`--fix`) в нём нет.

Чтобы автоматически починить часть нарушений, можно запустить **оригинальный**
`markdownlint` (JS-версия DavidAnson) через Docker с тем же конфигом, что
использует `dmt`. Он исправит большинство мелких проблем, а остальное придётся
править руками.

## Конфиг

Конфига в репозитории **нет** — его нужно создать самому. Сохраните приведённый
ниже файл, например, как `~/.markdownlint.yaml` (он эквивалентен тому, что зашит
в `dmt`).

```yaml
MD002: false
MD004: false
MD013:
  line_length: 1000
  heading_line_length: 128
  code_block_line_length: 400
  code_blocks: true
  tables: true
  headings: true
  headers: true
  strict: false
  stern: false
MD022:
  lines_above: 1
  lines_below: 1
MD024:
  siblings_only: true
MD026:
  punctuation: ".,;:!。，；：！"
MD029:
  style: one_or_ordered
MD032: false
MD033: false
MD041:
  level: 1
  front_matter_title: "^\\s*title\\s*[:=]"
MD042: true
MD044:
  names: []
  code_blocks: true
MD045: true
MD046:
  style: consistent
MD047: true
MD048:
  style: consistent
MD049:
  style: consistent
MD050:
  style: consistent
MD051: false
```

## Запуск через Docker

Из корня репозитория (конфиг монтируется из домашнего каталога отдельно):

```bash
docker run --rm \
  -v "$PWD:/md" \
  -v "$HOME/.markdownlint.yaml:/config.yaml:ro" \
  -w /md \
  ghcr.io/igorshubovych/markdownlint-cli:latest \
  --config /config.yaml \
  --fix \
  --ignore "**/README.md" \
  "docs/**/*.md"
```

Что делает команда:

- `-v "$PWD:/md"` — монтирует текущий каталог (репозиторий) внутрь контейнера в `/md`.
- `-v "$HOME/.markdownlint.yaml:/config.yaml:ro"` — монтирует ваш конфиг
  (только чтение). Поправьте путь, если положили файл в другое место.
- `-w /md` — рабочий каталог внутри контейнера.
- `--config /config.yaml` — использовать конфиг `dmt`.
- `--fix` — исправлять нарушения на месте (файлы меняются прямо в репозитории).
- `--ignore "**/README.md"` — пропустить `README.md`.
- `"docs/**/*.md"` — какие файлы обрабатывать (подстройте glob под себя).

Файлы правятся **на месте**, поэтому запускайте на чистом рабочем дереве, а
результат проверяйте через `git diff`.

## Запуск через CLI (без Docker)

Нужен установленный [Node.js](https://nodejs.org/). Используется тот же пакет,
что и в docker-образе — `markdownlint-cli`, версия **v0.49.0**.

Установить глобально (с пином версии):

```bash
npm install -g markdownlint-cli@0.49.0
markdownlint --version   # должно вывести 0.49.0
```

Запустить из корня репозитория (конфиг берётся прямо из домашнего каталога,
монтировать ничего не нужно):

```bash
markdownlint \
  --config ~/.markdownlint.yaml \
  --fix \
  --ignore "**/README.md" \
  "docs/**/*.md"
```

Либо разово, без глобальной установки, через `npx`:

```bash
npx -y markdownlint-cli@0.49.0 \
  --config ~/.markdownlint.yaml \
  --fix \
  --ignore "**/README.md" \
  "docs/**/*.md"
```

Флаги те же, что и у docker-варианта: `--config` — путь к конфигу, `--fix` —
исправлять на месте, `--ignore` — что пропустить, последний аргумент — glob
обрабатываемых файлов.

## Что чинится автоматически, а что руками

Автофикс закрывает большинство рутинных нарушений. Но часть правил `markdownlint`
исправить автоматически невозможно (нужно осмысленное вмешательство) — их
придётся править вручную.

### Исправляются автоматически (`--fix`)

MD005, MD007, MD009, MD010, MD011, MD012, MD014, MD018–MD023, MD026, MD027,
MD030, MD031, MD034, MD037, MD038, MD039, MD044, MD047, MD049, MD050, MD053,
MD058.

### Нужно править руками

Всё остальное, что не отключено в конфиге и не входит в список выше. В первую
очередь это:

- **MD013** — превышение длины строки/заголовка/блока кода: строки нужно
  переносить осмысленно, автофикс их не трогает.
- **MD024** — повторяющиеся заголовки (с учётом `siblings_only`).
- **MD025** — несколько заголовков верхнего уровня в документе.
- **MD029** — нарушение стиля нумерации в списках.
- **MD040** — у блока кода не указан язык.
- **MD041** — первый значимый блок файла должен быть заголовком H1.
- **MD042** — пустые ссылки.
- **MD045** — у изображения нет alt-текста.
- **MD046** — несогласованный стиль блоков кода (отступ vs. ограждение).
- **MD048** — несогласованный стиль ограждения блоков кода.
- **MD052** — ссылка/изображение ссылается на несуществующую reference-метку.

> Правила `MD002`, `MD004`, `MD032`, `MD033`, `MD051` в конфиге отключены
> (`false`) — они не срабатывают вообще.

## Рекомендуемый порядок работы

1. Запустить автофикс командой выше.
2. Посмотреть изменения: `git diff`.
3. Прогнать линтер `dmt` ещё раз — он покажет оставшиеся нарушения, которые
   автофикс не осилил.
4. Поправить их вручную по списку выше.
